# finalproject — сервис планирования задач

Итоговый проект курса Яндекс Практикум "Go-разработчик". Веб-сервис для планирования задач с поддержкой правил повторения, поиском и авторизацией.

## Что делает проект

Backend на Go, который хранит задачи в SQLite и отдаёт простой фронтенд. Через API можно добавлять задачи, получать список, редактировать, удалять и отмечать выполненными. Отдельно написана функция NextDate, которая вычисляет дату следующего выполнения задачи по правилу повторения.

Стек: Go, database/sql, SQLite (modernc.org/sqlite), JWT для авторизации, Docker.

## Что реализовано из необязательных заданий

- Правило повторения w (по дням недели)
- Правило повторения m (по дням и месяцам)
- Поиск задач по тексту (в заголовке и комментарии)
- Поиск задач по дате
- Авторизация по паролю (JWT)
- Docker (сборка образа + сохранение базы данных на хосте через volume)

## Как запустить локально

Нужен установленный Go.

    go run .

Переменные окружения:

    TODO_PORT — порт сервера, по умолчанию 7540
    TODO_DBFILE — путь к файлу базы данных, по умолчанию scheduler.db
    TODO_PASSWORD — пароль для входа, если не задан — авторизация не требуется

Пример:

    export TODO_PORT=7540
    export TODO_DBFILE=scheduler.db
    export TODO_PASSWORD=12345
    go run .

После запуска открыть в браузере:

    http://localhost:7540

## Как запустить тесты

Перед запуском тестов нужно поменять значения в tests/settings.go:

    Port — порт, на котором запущен сервер
    DBFile — путь к базе данных (../scheduler.db)
    FullNextDate — true, чтобы проверялись правила w и m
    Search — true, чтобы проверялся поиск
    Token — токен из /api/signin, если включена авторизация

Получить токен:

    curl -X POST http://localhost:7540/api/signin -d '{"password":"12345"}'

Запуск тестов (сервер должен быть запущен отдельно):

    go test ./tests

## Как запустить в Docker

Собрать образ:

    docker build -t scheduler .

Запустить контейнер с сохранением базы данных на хосте:

    docker run -p 7540:7540 -v ~/scheduler-data:/app/data scheduler

Если нужен пароль в контейнере:

    docker run -p 7540:7540 -v ~/scheduler-data:/app/data -e TODO_PASSWORD=12345 scheduler

Открыть в браузере:

    http://localhost:7540
